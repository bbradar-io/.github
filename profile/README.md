## What bbradar.io does

bbradar.io tracks public bug bounty and vulnerability disclosure programs across major Web2, Web3, contest, audit, and VDP platforms. It helps security researchers find fresh programs, monitor scope changes, compare platform activity, and search for targets that match their skills.

## Current Features

- **Unified program feed** - Track public bug bounty and VDP listings across supported platforms in one place
- **Latest Targets** - Monitor scope additions, removals, target changes, eligibility, and full target lists
- **Platform Intelligence** - Compare platform popularity, new-program momentum, 90-day trends, VDP share, reward profiles, and daily snapshots
- **Community voting** - Sign in with Google to vote on programs and platforms, with public popularity labels and rankings
- **Report-count metadata** - Surface report-count data when platforms expose it, with Pro access for premium counts
- **Pro API** - Query programs, program targets, target changes, target counts, activity metadata, and report counts
- **Live Discord alerts** - Receive new-program and target-change notifications through Pro channels
- **Advanced discovery** - Search by keyword, target, platform, language, scope tag, report count, votes, bounty visibility, and VDP visibility
- **Language and scope tags** - Filter by Python, JavaScript, TypeScript, Go, Rust, Solidity, Cairo, Clarity, Move, C, C++, Objective-C, Kotlin, Java, Sway, Swift, Ruby, AI/ML, blockchain-dlt, CIDR, domain, wildcard, smart contract, source code, package, and more
- **Dark and light mode** - Fast interface built for scanning and research

## Pro

Pro adds live monitoring and programmatic access on top of the free public feed:

- Live program notifications
- Live target-change notifications
- Full target visibility and target search
- Report counts where available
- Discord role and live notification channel access
- API keys for `/v1/pro/programs`, `/v1/pro/programs/{id}/targets`, and `/v1/pro/targets/changes`
- Monthly plan at EUR 8.99/month and yearly plan at EUR 89/year, with Stripe-powered billing and account self-service

## Platform Intelligence

The Platforms page is a live comparison dashboard, not just a list of sources:

- Platform popularity rankings from community votes
- Daily platform snapshots and 90-day new-program trendlines
- Active program counts, recent launches, VDP share, and reward profile summaries
- Platform-specific pages for quick filtering into the main program feed
- Free public access, with sign-in only needed when submitting votes
